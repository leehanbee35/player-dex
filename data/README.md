# 선수 명단 데이터

- `players.json`: 전체 선수 명단 (매주 월요일 05:00 KST에 ESPN 명단으로 자동 갱신)
- `photos.json`: 선수별 위키미디어 사진
- `ids.json`: ESPN 선수 → 도감 번호 (한 번 정한 번호는 바뀌지 않음)
- `ko.json`: 자동으로 만든 한글 표기 캐시

## 이름 고치기

자동으로 만든 한글 이름이 어색하면 `names.json`에 `"도감 번호": "고친 이름"`을 추가하면 됩니다.
도감 번호는 카드 왼쪽 위의 No.(앞의 0 제외)입니다.

```json
{
  "484": "일리만 은디아예",
  "483": "헤로니모 룰리"
}
```

GitHub 웹에서 이 파일을 고쳐 저장(Commit)하면 몇 분 뒤 명단이 다시 만들어지고 사이트에 반영됩니다.
매주 명단을 갱신해도 여기 적은 이름이 가장 우선합니다.

팀 이름도 같은 파일에서 고칠 수 있습니다. 키에 `t:`를 붙이고 ESPN 영문 팀 이름을 씁니다.

```json
{ "t:LAFC": "LAFC" }
```
