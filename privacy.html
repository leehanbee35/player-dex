개인정보처리방침

시행일: 2026년 11월 25일

풋볼 도감(이하 "사이트")은 회원 가입 없이 이용할 수 있으며, 서비스에 꼭 필요한 최소한의 정보만 처리합니다. 이 방침은 사이트가 어떤 정보를 어떤 목적으로 처리하는지 설명합니다.

1. 처리하는 정보

구분항목목적보관 기간
댓글 작성닉네임, 댓글 내용, 비밀번호(복원할 수 없는 형태로 암호화), IP 주소 앞 두 자리, IP 주소를 변환한 값(원래 주소로 되돌릴 수 없음)댓글 표시, 작성자 본인의 삭제, 도배·악용 방지댓글을 삭제할 때까지
추천·비추천·신고IP 주소를 변환한 값같은 사람이 여러 번 누르는 것을 막기 위함해당 댓글을 삭제할 때까지
이용 설정즐겨찾기, 필터·정렬, 화면 밝기, 마지막으로 쓴 닉네임다음 방문 때 같은 화면을 보여 주기 위함이용자의 브라우저에만 저장되며 사이트로 전송되지 않습니다. 브라우저 설정에서 언제든 지울 수 있습니다.

사이트는 이름, 연락처, 이메일 같은 개인 식별 정보를 수집하지 않습니다.

2. 처리를 맡기는 곳과 외부 서비스

사이트를 운영하기 위해 아래 서비스를 이용합니다. 페이지를 열거나 기능을 쓸 때 이용자의 브라우저가 각 서비스에 직접 접속하며, 이 과정에서 IP 주소 등 접속 정보가 각 서비스에 전달될 수 있습니다. 각 서비스의 개인정보 처리는 해당 서비스의 방침을 따릅니다.

  • 사이트 호스팅: GitHub Pages (사이트 파일 전송)
  • 댓글 저장: Supabase (1번 표의 댓글 정보 저장)
  • 선수 사진: 위키미디어 공용(Wikimedia Commons)
  • 국기 이미지·시즌 기록·경기 정보·해외 리그 팀 순위: ESPN
  • K리그 경력 기록·K리그 팀 순위: 한국어 위키백과
  • 팀 정보(감독·홈구장·창단·리그 우승 기록): 위키데이터(Wikidata), 위키백과
  • 글꼴: Google Fonts

뉴스 반응은 사이트가 미리 모아 둔 기사 제목을 분류한 결과이며, 이 과정에서 이용자의 정보는 쓰이지 않습니다.

3. 광고

현재 사이트에는 광고가 없습니다. 앞으로 광고(예: 카카오 애드핏, Google AdSense)나 제휴 링크(예: 쿠팡 파트너스)를 넣게 되면, 광고 회사가 쿠키 등을 이용해 광고를 보여 줄 수 있습니다. 그때 이 방침에 광고 회사와 처리 내용을 추가하고 시행일을 고쳐 알립니다. 제휴 링크가 있는 곳에는 그 사실을 함께 표시합니다.

4. 이용자의 권리

  • 자신이 쓴 댓글은 작성할 때 정한 비밀번호로 언제든 삭제할 수 있습니다. 삭제하면 1번 표의 댓글 정보도 함께 지워집니다.
  • 비밀번호를 잊어 삭제할 수 없거나 정보 처리에 대해 문의할 일이 있으면 아래 문의처로 연락해 주세요.
  • 브라우저에 저장된 이용 설정은 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.

5. 안전성 확보

댓글 비밀번호는 복원할 수 없는 방식으로 암호화해 저장하고, IP 주소는 앞 두 자리와 되돌릴 수 없는 변환 값만 저장합니다. 댓글 저장소는 사이트의 정해진 기능으로만 쓰고 지울 수 있도록 접근을 제한합니다.

6. 문의

개인정보 처리에 관한 문의는 GitHub 문의 게시판으로 남겨 주세요.

7. 방침 변경
